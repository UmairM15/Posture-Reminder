Super simple script that reminds you to fix your posture every 30 seconds to 5 minutes.

Make sure you download the right one for your OS (Mac or Windows)!

# Installation

## Windows
Head over to the Releases tab and install the .exe file. Run it to start the script, close it to end the script. Simple.

## MacOS
MacOS comes with Python installed, so just run download and run the .py file.
